Project overview

This assignment explores two cybersecurity topics: recognizing phishing websites using machine learning, and demonstrating why unsafe SQL query construction can expose an application to injection attacks.

The phishing analysis uses a publicly available Kaggle dataset with 10,000 original rows, 48 features, and the target variable CLASS_LABEL. The SQL injection portion is a separate controlled local SQLite lab.

Dataset source: Phishing Dataset for Machine Learning — Kaggle ↗

How to reproduce the analysis

  1. Install Python 3.10 or later.
  2. From the repository directory, run pip install -r requirements.txt.
  3. Run python analysis.py, or open 02_Phishing_Analysis.ipynb.
  4. Review outputs in the figures/ folder.
  5. For the separate controlled SQL injection example, run python 05_SQL_Injection_Lab.py.
